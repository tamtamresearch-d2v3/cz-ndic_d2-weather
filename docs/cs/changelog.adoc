== Historie změn dokumentace

// Revize dokumentace (MAJOR.MINOR.REVIZE). Změny formátu viz CHANGELOG.adoc ve specifikaci.
=== 2.0.0

* Nová dokumentace formátu `cz-ndic_d2-weather` verze 2.0 (DATEX II 3.7); nahrazuje dokumentaci formátu
  cz-ndic_d2-weather-v1.2 (DATEX II 2.3).
* Změny oproti verzi 1.2 (DATEX II 2.3):
** Formát je převeden na model DATEX II 3.7. Obálky `d2LogicalModel` a `exchange`
   se nepoužívají; kořen je `d2:payload`, formát určují atributy `@profileName` a `@profileVersion`.
** `safetyRelatedMessage` je součástí modelu (dříve národní rozšíření).
** Neuvádějí se naléhavost (`urgency`), příčina (`cause`) ani typ zdroje (`sourceType`); komentář obsahuje jen popis
   jevu.
** Kluzká vozovka z povětrnostní příčiny je `slippery` (dříve `slipperyRoad`).
** Odkaz na skupinu poloh je `loc:LocationGroupByReference`, `@targetClass` s prefixem `loc:`.
