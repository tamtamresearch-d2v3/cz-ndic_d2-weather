== Documentation change history

// Documentation revisions (MAJOR.MINOR.REVISION). Format changes: see CHANGELOG.adoc in the specification.
=== 2.0.0

* New documentation of the `cz-ndic_d2-weather` format version 2.0 (DATEX II 3.7); replaces the
  documentation of the cz-ndic_d2-weather-v1.2 format (DATEX II 2.3).
* Changes compared to version 1.2 (DATEX II 2.3):
** The format has been migrated to the DATEX II 3.7 model. The `d2LogicalModel`
   and `exchange` envelopes are not used; the root is `d2:payload`, the format is identified by the
   `@profileName` and `@profileVersion` attributes.
** `safetyRelatedMessage` is part of the model (formerly a national extension).
** Urgency (`urgency`), cause (`cause`) and source type (`sourceType`) are not given; the comment contains only the
   description of the phenomenon.
** Slippery road due to weather is `slippery` (previously `slipperyRoad`).
** A reference to a location group is `loc:LocationGroupByReference`, `@targetClass` with the prefix `loc:`.
